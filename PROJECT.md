# IS218 Test 1

Name: Jiyeon Choi

## Purpose
This project implements and tests basic addition and subtraction functions using Python and pytest.

## Setup
1. Create the virtual environment with `python3 -m venv .venv`.
2. Activate it with `source .venv/bin/activate`.
3. Install dependencies with `python -m pip install -r requirements.txt`.

## Testing
Run all tests with `pytest`.
